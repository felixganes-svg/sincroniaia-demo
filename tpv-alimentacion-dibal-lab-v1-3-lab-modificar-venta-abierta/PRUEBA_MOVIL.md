# PRUEBA RÁPIDA · MODIFICAR VENTA ABIERTA

## Cliente ya no quiere un artículo

1. Haz la venta normalmente.
2. Pulsa **SUBTOTAL**.
3. Pulsa **MODIFICAR VENTA**.
4. Busca el artículo.
5. Pulsa **MODIFICAR**.
6. Selecciona el motivo **Cliente no lo quiere**.
7. Pulsa **RETIRAR ARTÍCULO**.
8. Confirma.
9. Vuelve al Subtotal y comprueba el total.

## Si el peso está mal

1. SUBTOTAL → MODIFICAR VENTA.
2. MODIFICAR en la línea.
3. Escribe el peso/cantidad correcto.
4. Selecciona el motivo.
5. GUARDAR CAMBIO.

## Control de Empresa

Empresa → **Modificaciones venta abierta**.

Ahí debe quedar el histórico del cambio.

## Regla

Esto solo sirve antes de cobrar. Si el ticket ya está cerrado, se usa **Rectificación autorizada**.
