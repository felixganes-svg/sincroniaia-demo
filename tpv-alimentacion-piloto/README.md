# SINCRONIAIA TPV Alimentación · Piloto local

Piloto independiente de la demo DIBAL LAB v1.28. No comparte sus datos ni modifica sus archivos.

## Funcionamiento

- Guarda empresa, vendedores, artículos, ventas, tickets, encargos e informes en el dispositivo.
- Puede abrirse sin Internet después de la primera carga y de instalarse en la pantalla de inicio.
- Permite exportar una copia completa JSON y listados CSV de artículos y tickets.
- Incluye una hoja Excel de artículos y estructura de tickets como plantilla de control.

## Copias de seguridad

Desde `Empresa > Datos locales y copias`, pulsa `Descargar copia completa`. Conserva ese JSON fuera del dispositivo. La opción `Restaurar una copia` sustituye los datos locales actuales.

## Alcance

Este piloto está pensado para un único ordenador o tablet. Para que varios equipos trabajen simultáneamente con los mismos datos hará falta un servidor local o una sincronización central.
