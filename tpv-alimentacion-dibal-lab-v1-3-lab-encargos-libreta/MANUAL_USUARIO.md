# SINCRONIAIA TPV ALIMENTACIÓN
## Manual de usuario / vendedor

> Documento de trabajo para la LAB actual. No implica todavía validación final para cliente real.

## 1. Acceso
1. Abrir el TPV desde el acceso instalado o desde la URL de la LAB.
2. Entrar en **VENDEDORES**.
3. Iniciar el vendedor correspondiente.
4. Entrar en **VENTA**.

## 2. Venta normal
1. Elegir la sección.
2. Elegir subsección o localizar el artículo por Código / A-Z.
3. Seleccionar el artículo.
4. Introducir peso o unidades según el producto.
5. Confirmar la línea.
6. Continuar vendiendo o pulsar **SUBTOTAL**.

## 3. Subtotal
El subtotal es solo de consulta.
- Muestra líneas.
- Muestra cantidades/pesos.
- Muestra precios.
- Muestra total provisional.
- No permite eliminar líneas directamente.

Si hay que corregir una venta, debe hacerse por el circuito autorizado correspondiente.

## 4. Cobro
Formas disponibles:
- Efectivo.
- Tarjeta.
- Bizum.
- Mixto.

### Efectivo
- Si no se introduce importe entregado, se interpreta como pago exacto.
- Si se introduce más dinero, calcula devolución.
- Si se introduce menos del total, bloquea el cierre.

### Mixto
El pago mixto debe repartirse entre al menos dos medios:
- Efectivo.
- Tarjeta.
- Bizum.

La suma debe coincidir exactamente con el total del ticket.

Ejemplo:
- Total: 50,00 €
- Efectivo: 20,00 €
- Tarjeta: 30,00 €

El ticket mostrará **Pago: MIXTO** y el desglose real.

## 5. Encargos
1. Entrar en **ENCARGOS**.
2. Crear o recuperar un encargo.
3. Añadir artículos.
4. Introducir directamente el peso/unidades de cada línea al prepararla.
5. Seleccionar qué vendedor prepara la línea.
6. Guardar la línea.
7. Las líneas preparadas pasan a la zona de preparados.
8. Se puede duplicar una línea o añadir nuevas líneas mientras no exista ticket definitivo.
9. El encargo puede aparcarse y volver a venta.
10. Cuando todas las líneas estén resueltas, puede marcarse como completado.
11. Después se genera la venta/ticket.
12. El ticket puede cobrarse en el momento o recuperarse desde Encargos → Por cobrar.

## 6. Tickets
Los tickets cerrados no se modifican directamente.

Si existe un error:
- se solicita la rectificación,
- requiere autorización,
- se genera un ticket rectificativo relacionado,
- el original permanece intacto.

## 7. Informe personal
Cada vendedor puede consultar su actividad autorizada:
- tickets,
- efectivo,
- tarjeta,
- Bizum,
- venta total.

Los pagos mixtos se reparten por su forma real.

## 8. Buenas prácticas
- No compartir PIN de vendedor.
- No cerrar ventas con el vendedor equivocado.
- Comprobar peso/cantidad antes de confirmar.
- Si hay un error en un ticket cerrado, no intentar borrarlo: usar rectificación.
- En caso de duda, avisar al responsable.
